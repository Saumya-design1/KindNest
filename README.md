## 🌱 About the Project

**KindNest** is a responsive NGO-inspired website designed to promote kindness, community service, and social responsibility.

The website encourages people to contribute to meaningful causes, explore community initiatives, and register as volunteers. With a clean layout, nature-inspired colors, and simple interactive elements, KindNest demonstrates how basic web technologies can be used to create an engaging platform for social good.

> 💚 Small acts of kindness can create a big difference.

## ✨ Features

- 🏡 **Beautiful Landing Page** — Welcoming hero section with a clear call to action.
- 📊 **Impact Dashboard** — Displays illustrative statistics about people supported, volunteers, community drives, and partner communities.
- 🎯 **Causes Section** — Highlights education, food security, and environmental protection.
- 🙋 **Volunteer Registration Form** — Collects a volunteer's name, email, phone number, preferred activity, and motivation.
- ⚡ **JavaScript Interactivity** — Displays a personalized confirmation message after form submission.
- 📱 **Responsive Design** — Includes layouts adapted for smaller screens.
- 🧭 **Smooth Navigation** — Provides links to different sections of the website.
- 🎨 **Modern UI** — Features soft colors, rounded cards, imagery, and subtle hover effects.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structures the website and its content. |
| CSS3 | Handles layouts, colors, typography, animations, and responsive styling. |
| JavaScript | Processes the volunteer form and displays a confirmation message. |

No external JavaScript libraries or frameworks are required.

## 🚀 Getting Started

Follow these simple steps to run KindNest locally.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your GitHub username and repository name.

### 2. Navigate to the project folder

```bash
cd YOUR-REPOSITORY
```

### 3. Open the website

Open `index.html` in your browser.

Alternatively, open the project in Visual Studio Code and use the **Live Server** extension to preview the website.

## 📝 How It Works

### Explore the website

Browse the homepage, learn about the featured causes, and explore the community impact section.

### Choose a cause

Discover initiatives related to education, food distribution, and environmental protection.

### Register as a volunteer

1. Enter your name and email address.
2. Provide your phone number.
3. Select your preferred volunteering activity.
4. Optionally explain why you want to volunteer.
5. Submit the form to view a personalized confirmation message.

**Important:** This is a front-end demonstration project. Form submissions are handled in the browser only; information is not saved to a database or sent to an NGO.

The displayed impact statistics are illustrative figures for demonstration purposes.
